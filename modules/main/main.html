建置及操作說明

示範說明影片

下載原始碼

原始碼網址：https://github.com/kentxchang/classtools_cloudflare

  1. 點上方網址進入 GitHub 頁面。
  2. 按右上方綠色的 <> Code 按鈕，再點選 Download ZIP 下載壓縮檔。
  3. 在下載的 ZIP 檔上按右鍵，選「解壓縮全部」，解壓縮後會得到 classtools_cloudflare-main 資料夾，接著依照以下步驟部署。

部署到 Cloudflare（用指令，最推薦）

事前準備：註冊 Cloudflare 帳號（dash.cloudflare.com/sign-up），並安裝 Node.js LTS 版（nodejs.org）。

步驟 1：在本資料夾打開命令視窗

  1. 用檔案總管打開解壓縮後的 classtools_cloudflare-main 資料夾（看得到 wrangler.jsonc 那一層）。
  2. 點一下上方的網址列，把內容改成 cmd 後按 Enter，就會在這個資料夾開啟命令提示字元。

步驟 2：登入 Cloudflare

輸入：

npx wrangler login
  • 第一次執行會問 Need to install the following packages ... Ok to proceed? (y)，輸入 y 按 Enter。
  • 瀏覽器會自動打開 Cloudflare 授權頁面，按 Allow（允許）。
  • 看到 Successfully logged in 就完成了，可以關掉該網頁。

步驟 3：部署

輸入：

npx wrangler deploy
  • 如果是第一次使用 Cloudflare Workers，會請你設定一個 workers.dev 子網域（例如輸入 mrchang），這會成為網址的一部分，之後不能隨意更改，請取一個好記的英文名稱。
  • 完成後會顯示網址，例如：https://classtools.mrchang.workers.dev

這就是你的剛好學網址！老師和學生都用這個網址進入。

💡 網址前半段來自 wrangler.jsonc 裡的 "name"，想改名可以在部署前修改這一行（只能用英文小寫、數字和 -）。

步驟 4：資料庫設定？——已經自動完成了！

wrangler.jsonc 已經寫好資料庫設定，npx wrangler deploy 時 Cloudflare 會自動建立資料庫，不需要另外到後台建立或貼任何設定。

想確認的話：

  1. 登入 dash.cloudflare.com
  2. 左側選單點 Workers & Pages（運算 → Workers & Pages）
  3. 點進你的 Worker，在「繫結 / Bindings」區域會看到名為 ROOMS 的 Durable Object，這就是資料庫。
  4. 每開一間教室，就會自動產生一個該教室專用的資料庫；按下「下課」時會清空該教室的資料。
