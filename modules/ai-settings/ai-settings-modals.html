AI 服務設定

Gemini 使用說明：
• 選擇 Preview 預覽模型可免 API Key 直接測試 AI 功能
• 建議填入個人 Gemini API Key 享受更高生成配額與穩定度

預設為 http://localhost:11434

本地 Ollama 提示：
• 請確認電腦終端機已啟動 Ollama (ollama serve)
• 若瀏覽器提示跨網域 (CORS) 阻擋，請設定允許跨來源後啟動：
  OLLAMA_ORIGINS="*" ollama serve

macOS 本地 Apple AI： 支援調用 macOS 最新系統內建下載的 Apple AI 模型 (Apple Intelligence 3B AFM)。

afm-Server 預設為 http://localhost:11435；apple-to-openai / maclocal-api 預設為 http://localhost:8000

Apple Intelligence 本地模型說明：
• 適用於 Apple Silicon (M系列晶片) Mac，需在系統設定中開啟 Apple Intelligence 並下載模型
• 配合輕量本地伺服器（如 afm-Server、maclocal-api 或 apple-to-openai）轉接，即可完全離線由 Mac 內建晶片執行生成，免金鑰、零網路延遲！
